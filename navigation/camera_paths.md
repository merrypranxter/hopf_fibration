# Camera Paths Through S³

## The Space We Are Flying Through

S³ is not a torus. It's not a 3D sphere. It's the space of unit quaternions — a 3-manifold that closes back on itself in a way that 3D Euclidean space never does.

When we "navigate" S³, we're choosing a basepoint (a unit quaternion q) and projecting the fibration from that viewpoint using stereographic projection. Moving q moves our viewpoint in 4D, which deforms the projected image in R³.

## Two Modes of Motion

### Left Action: Moving Between Fibers

```
q · p   (left multiply all points by q)
```

Equivalent to rotating the base sphere S². This permutes the fibers — the nested tori shift, the colors swirl. The structure is preserved (linking numbers unchanged), but the visual arrangement changes dramatically.

**Good for**: Revealing the global symmetry of the fibration.

### Right Action: Moving Within a Fiber

```
p · q   (right multiply)
```

This moves each point within its fiber. The base point on S² is unchanged, but the fiber parameter t shifts. Visually: the colored rings spin in place.

**Good for**: Demonstrating that the fibers are circles and the Hopf map is the projection.

### Combined: Exploring SO(4)

Left and right action together span all of SO(4) — every isometry of S³. A simultaneous left rotation at speed ω₁ and right rotation at speed ω₂ gives:

- If ω₁ = ω₂: Clifford translation (uniform motion on S³, no fixed points)
- If ω₁ = -ω₂: another type of Clifford translation in the opposite chirality
- Generic: precessing motion that densely covers S³

## Implemented Paths

### 1. Great Circle in XW Plane
`q(t) = (sin(t), 0, 0, cos(t))`

The simplest path: a great circle on S³. Starts at identity (1,0,0,0), passes through (i) = (1,0,0,0) at t=π/2, through antipode (-1,0,0,0) at t=π, and returns.

- Period: 2π
- Covers: Every coset of the U(1) subgroup generated by i
- Visual: The projected fibration continuously rotates, with fibers flowing through the frame

### 2. Fiber Orbit
Stay within a single Hopf fiber.

- Period: 2π
- Covers: One fiber
- Visual: You are "inside" one fiber, spinning with it. The fiber you're on appears to be "your" fiber at infinity.

### 3. Screw Path
`q(t) = e^(t·ω₁·i) · e^(t·ω₂·j)`

Simultaneous left and right rotation at different rates. The path is dense on a 2-torus inside S³.

- Period: 2π / gcd(ω₁, ω₂) (or irrational period for incommensurable speeds)
- Visual: Continuous fiber morphing with no obvious repetition

### 4. Geodesic Interpolation (SLERP)
Shortest path between any two quaternions on S³.

- Used for: Smooth transitions between keyframe positions
- Formula: `q(t) = (sin((1-t)·θ)·a + sin(t·θ)·b) / sin(θ)` where θ = arccos(a·b)

### 5. Figure-Eight
`q(t) = normalize(sin(t), sin(2t)/2, 0, cos(t))`

Passes through the identity twice per period. Creates a visually interesting non-trivial loop.

## Coordinate System

After projection, the 3D image lives in R³ with:
- The identity quaternion (1,0,0,0) projecting to the origin
- The j-axis fiber lying along the y-axis
- Scale determined by the projection formula: (x,y,z)/(1-w)

The "natural" camera position is along the positive z-axis at distance 3-5 units, looking at the origin.

## Implementation

See `quaternion_camera.glsl` for GLSL implementations of all paths.

For Three.js / JavaScript interaction:
```javascript
// Mouse drag → quaternion rotation
function mouseToQuat(dx, dy, sensitivity = 0.01) {
    const axis = new THREE.Vector3(-dy, dx, 0).normalize();
    const angle = Math.sqrt(dx*dx + dy*dy) * sensitivity;
    return new THREE.Quaternion().setFromAxisAngle(axis, angle);
}

// Apply left action
scene.userData.navQuat.premultiply(mouseToQuat(dx, dy));
scene.userData.navQuat.normalize();
```

---

*In S³, every direction is "forward." The geometry has no preferred orientation. When you fly through it, you are not moving through space — you are applying group elements.*
